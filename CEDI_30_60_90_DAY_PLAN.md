# BuildMe — 30/60/90 Day CEDI Plan

---

## Days 1–30: Discovery & Pilot Recruitment

### Customer Discovery (Week 1-2)
- [ ] Conduct 5 customer discovery interviews with civil engineers
- [ ] Complete feedback templates for each interview
- [ ] Identify biggest pain points and willingness to pay
- [ ] Refine product positioning based on findings

### Pilot Recruitment (Week 2-3)
- [ ] Leverage father's network for pilot candidate
- [ ] Present BuildMe to 2-3 potential pilot engineers
- [ ] Select ONE pilot project
- [ ] Complete pilot onboarding

### Pilot Execution (Week 3-4)
- [ ] Generate BuildMe estimate for pilot project
- [ ] Compare with engineer's own estimate/quotation
- [ ] Set up expense tracking
- [ ] Collect initial feedback

### Deliverables
- 5 completed customer discovery interviews
- 1 active pilot project
- BuildMe estimate generated and compared
- Initial engineer feedback collected

---

## Days 31–60: Pilot Execution & Evidence Collection

### Pilot Monitoring (Week 5-8)
- [ ] Track project progress
- [ ] Record expenses as they occur
- [ ] Collect ongoing feedback
- [ ] Document any issues or surprises

### Additional Pilots (Week 6-8)
- [ ] Recruit 1-2 additional pilot candidates
- [ ] Onboard second pilot if first is progressing well
- [ ] Start building multi-project evidence

### Product Refinement (Week 7-8)
- [ ] Fix issues identified during pilot
- [ ] Improve usability based on feedback
- [ ] Enhance estimation methodology if needed

### Deliverables
- Pilot project actively tracked
- 3+ expenses recorded
- Engineer feedback collected
- 1-2 additional pilots recruited

---

## Days 61–90: Validation & ML Assessment

### Ground Truth Collection (Week 9-12)
- [ ] If any project completes: record final cost
- [ ] Compare BuildMe estimate with actual
- [ ] Calculate initial validation metrics (if ≥3 observations)
- [ ] Document findings

### ML Feasibility Assessment (Week 10-12)
- [ ] Assess dataset size for ML training
- [ ] Identify feature engineering requirements
- [ ] Determine if ML is feasible with current data
- [ ] Create ML readiness report

### Business Model Testing (Week 11-12)
- [ ] Test pricing hypotheses with pilot engineers
- [ ] Determine willingness to pay
- [ ] Refine business model based on evidence

### Deliverables
- Ground-truth observation (if project completed)
- ML feasibility assessment
- Business model validation results
- CEDI progress report

---

### 30-Day Targets
