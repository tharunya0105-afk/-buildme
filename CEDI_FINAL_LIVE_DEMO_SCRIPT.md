# BuildMe — CEDI Final Live Demo Script

**Duration**: 3 minutes
**Goal**: Make the evaluator understand BuildMe's value, honesty, and next steps

---

## 0:00–0:30 — THE PROBLEM (30 seconds)

**Action**: Show the BuildMe homepage.

**Say**:

> "Construction cost estimation in India is fragmented. Engineers use government benchmarks that don't reflect local prices. Contractor quotations vary 40-60% for similar scope. Material prices change quarterly but estimates are static. BuildMe brings these sources into one transparent workflow."

**Show**: The homepage workflow diagram.

---

- Location: Coimbatore
- Area: 1800 sqft
- Floors: 2
- Quality: Standard

> "I'll enter a real project: Coimbatore, 1800 square feet, 2 floors, standard quality."

---

## IF ASKED: "How accurate is it?"

> "I don't know yet. We have 0 completed projects to compare against. The estimate is transparent and reproducible, but accuracy requires real-world validation. That's what the pilot is for."

## IF ASKED: "Where is the AI?"

> "BuildMe's current intelligence is rule-based, not AI. An AI document extraction pipeline exists but requires an API key we don't have yet. We're not claiming AI capabilities we don't have."

## IF ASKED: "How many users?"

> "Zero. The product exists but hasn't been used by anyone other than me. We're currently recruiting civil engineers for the first pilot."

## IF ASKED: "How will you make money?"

> "We have pricing hypotheses — subscription or per-project. All are unvalidated. The first step is to determine whether engineers find BuildMe valuable enough to use, then test willingness to pay."

## IF ASKED: "What makes this different from a calculator?"

> "A calculator computes. BuildMe connects government data, market evidence, and project tracking into a transparent system. The value is in the connections, not the calculation."

---

## RULES

1. Never claim accuracy — you don't have the evidence
2. Never call it AI — it's rule-based
3. Never show fabricated data — only real data
4. Always show the "not proven" section — honesty builds credibility
5. Always end with the ask — what you need from CEDI
