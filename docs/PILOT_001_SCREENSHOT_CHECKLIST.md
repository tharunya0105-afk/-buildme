## Screenshot Guidelines

1. **Use genuine data** where possible
2. **Blur or omit** personal information
3. **Show the flow** — input → estimate → save → track → expense
4. **Include source transparency** — this is BuildMe's key differentiator
5. **Show honest empty states** where data doesn't exist yet
6. **Never fabricate** data for screenshots

## Presentation Order

For a 5-minute CEDI demo, show screenshots in this order:

1. Project Input (0:00)
2. Generated Estimate (0:30)
3. Source Transparency (0:45)
4. Save to Project (1:00)
5. Budget Tracking (1:15)
6. Expense Recording (1:30)
7. Ground Truth Dashboard (2:00)
8. Validation Dashboard (2:30)
9. CEDI View — Proven vs Not Proven (3:00)
10. Narrative: "We haven't fabricated traction" (3:30)
